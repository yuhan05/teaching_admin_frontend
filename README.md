## 2 系统概述
### 2.1 系统简介
本系统为基于 Python 开发的教学管理前端应用，通过对接教学管理服务 API 实现与后端服务器的数据交互，为学生提供账号管理、作业查询提交、成绩查看与数据可视化等核心功能，支持Web 浏览器使用。

### 2.2 核心功能
- 账号登录与安全注销
- 个人基本信息查询
- 作业列表查询与作业文件提交
- 作业提交记录查询
- 作业成绩查询
- 成绩数据统计与图表可视化

### 2.3 技术架构
| 模块 | 技术选型 |
|------|----------|
| 开发语言 | Python 3.x |
| 界面框架 | Streamlit |
| 网络请求 | requests |
| 数据可视化 | Plotly |
| 数据交互 | 教学管理服务 RESTful API |

## 3 运行环境与安装部署
### 3.1 环境要求
#### 3.1.1 硬件要求
- 处理器：Intel Core i3 及以上
- 内存：4GB 及以上
- 硬盘：剩余可用空间 ≥ 500MB

#### 3.1.2 软件要求
- 操作系统：Windows 10/11、macOS 10.15+、Linux Ubuntu 20.04+
- Python 版本：Python 3.8 及以上
- 网络环境：可正常访问教学管理服务 API 服务器

### 3.2 安装步骤
1. **解压程序包**  
   将提交的源代码压缩包解压至本地任意目录，解压后目录结构参考附录 A。

2. **安装依赖库**  
   打开终端/命令提示符，进入程序根目录，执行以下命令安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. **配置系统参数（可选）**  
   打开 `config.py` 文件，确认 API 服务器地址与实际环境一致：
   ```python
   BASE_URL = "https://pysummer.pkuai.cc/api/v1"
   ```

### 3.3 启动运行
- **Web 应用**：在终端进入程序根目录，执行以下命令启动：
  ```bash
  streamlit run main.py
  ```
- 启动成功后，在浏览器中访问提示的本地地址（如 `http://localhost:8501`）。

## 4 功能操作指南
### 4.1 账号登录与注销
#### 4.1.1 登录系统
1. 启动系统后，进入登录界面；
2. 在对应输入框填写**用户名**与**登录密码**；
3. 点击「登录」按钮，系统将向服务器发起身份验证；
4. 验证成功后自动跳转至系统主界面，验证失败将弹出错误提示（用户名/密码错误、网络异常等）。

> 注意：请确保网络连接正常，登录凭证由教学管理服务统一分配。

#### 4.1.2 注销账号
1. 在首页/侧边栏找到「退出登录」按钮；
2. 点击后退出，系统将清除本地登录状态并返回登录界面。

### 4.2 个人信息查询
1. 登录成功后，在首页可查看个人信息；
2. 页面将展示从服务器同步的个人信息，包括姓名、学号、角色；
3. 该页面仅支持查看，不可编辑修改。

### 4.3 作业信息管理
#### 4.3.1 查询作业列表
1. 点击侧边栏「作业管理」→ 顶边栏「作业列表」；
2. 系统自动拉取所有已发布的作业栏目
3. 选择需要查询的作业栏目，点击「查看作业详情」，展示作业截止时间、作业状态（未提交/已提交/已截止）、成绩、作业说明等；

#### 4.3.2 查询作业提交记录
1. 点击侧边栏「作业管理」→ 顶边栏「作业列表」；
2. 系统自动拉取所有已发布的作业栏目
3. 选择需要查询的作业栏目，点击「查看提交历史」，展示提交版本；
4. 选择需要查看的版本，可查看文本内容、作业文件和LLM聊天文件，点击下载可下载对应文件

#### 4.3.3 提交作业
1. 点击侧边栏「作业管理」→ 顶边栏「提交作业」；
2. 在「选择作业」栏下拉选择需要提交的作业；
3. 可在备注框中填写作业说明（可选）；
4. 点击「Browse files」，选择本地作业文件（Limit 200MB per file • TXT, PY, IPYNB, PDF, ZIP）；
5. 点击「Browse files」，选择本地LLM聊天文件（Limit 200MB per file • MD）；
6. 点击「确认提交」，系统上传文件并返回提交结果；

> 注意：截止时间过后无法提交作业；同一作业可多次提交，以最后一次提交内容为准。


### 4.4 作业成绩查询
1. 点击侧边栏「成绩查询」；
2. 系统以表格展示所有作业的成绩信息，包含作业名称、满分、得分、评语、 发布时间；
3. 可按作业名称、得分、发布时间等进行排序操作。

> 注意：未评分的作业成绩为「NA」，发布时间为「NA」。

### 4.5 统计分析与可视化
1. 点击侧边栏「统计分析」进入可视化页面；
2. 可视化界面上部为学习进度模块，展示以下图表：
   - 提交率：已提交和未提交的作业数量比例
   - 提交情况分布：按时提交、迟交和未提交的比例
   - 评分进度：已评分和未提交的作业数量比例
3. 可视化界面下部为成绩分析模块，对所有作业成绩进行统计分析，展示以下图表：
   - 平均得分和平均得分率
   - 各次作业得分柱状图
   - 各次作业得分率趋势散点图
4. 图表支持缩放、导出为图片。

## 5 常见问题与故障排查
| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 点击登录无响应/提示网络错误 | 网络不通、API 地址配置错误 | 1. 检查网络连接是否正常；2. 确认 config.py 中 API 地址与端口正确 |
| 登录提示用户名或密码错误 | 账号信息有误、大小写错误 | 核对账号密码，注意区分大小写；联系管理员确认账号状态 |
| 作业文件上传失败 | 文件过大、格式不支持、网络波动 | 1. 检查文件大小是否超出限制；2. 确认文件格式在允许范围内；3. 重试上传 |
| 提交作业后未显示在提交记录中 | 服务器响应延迟 | 1. 刷新页面或重新登录；2. 检查网络连接是否正常；3. 重新执行提交操作 |
| 成绩图表不显示 | 可视化库未安装、无成绩数据 | 1. 确认 matplotlib/echarts 等依赖安装成功；2. 确认存在已批改的作业成绩 |
| 程序启动报错 | Python 版本不兼容、依赖缺失 | 1. 检查 Python 版本 ≥ 3.8；2. 重新执行 `pip install -r requirements.txt`；3. 尝试使用 Python 模块方式运行：`python -m streamlit run main.py`|

## 6 创新点

**应用功能**，本系统功能全面，涵盖了作业查询、作业提交、作业下载、成绩查询、统计分析等模块，功能分区划分合理，提供高效、便捷的使用体验。   
**网页设计风格**，本系统采用了现代、简洁、清晰的后台管理风格（Admin Dashboard Style），使用经典的“侧边栏 + 顶部栏 + 内容区”三明治结构，信息层级分明、留白舒适、操作引导清晰，符合教育行业的行业调性，传递稳重、可信、专业的视觉感受。   
**个性化设置**，本系统支持用户自定义主题颜色和页面宽度，以满足不同用户的需求和偏好。
